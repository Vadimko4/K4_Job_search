# Проект "K4_Job_search"

## Описание:

Проект является курсовой работой к четвёртому модулю обучающего курса Skypro "Профессия Python-разработчик".
Посвящён получению и анализу вакансий с сервиса HH.ru
Что касается парадигмы в которой написан проект, то здесь преимущественно использовано объектно ориентированное 
программирование. 

## Описание модулей:

### main
«Точка входа» — модуль, запустив который, можно получить результат всех реализованных в проекте функциональностей.
Интерфейс пользователя реализован двумя основными функциями, которые воплощают два основных меню. 

Основное меню пользователя, содержит команды:

1. Фильтрация по зарплате
2. Фильтрация по ключевым словам в описании
3. Вывести ТОП найденных вакансий по зарплате
4. Вывести все вакансии
5. Действия с файлом
6. Сбросить все фильтры
7. Новый поиск
8. Ещё раз показать главное меню
9. Выход из программы

Во втором меню пользователь работает с файлами:
1. Записать текущие вакансии в файл
2. Загрузить вакансии из файла
3. Вернуться в главное меню

Файловое меню в процессе использования распадается на логично вытекающие для пользователя возможности по созданию 
нового файла, перезаписи или дозаписи данных в существующие файлы, считывание данных из существующих файлов для 
их последующего анализа, фильтрации и дополнения.
Его создание не было обязательным, но автор, увлёкшись, посчитал реализацию данной опции возможной и даже необходимой
для удобного использования программы.

Так же в данном модуле реализованы все вспомогательные функции, необходимые для реализации самого интерфейса 
пользователя. В частности моменты ввода данных пользователем через консоль обслуживают специальные функции. В них 
реализована "защита от дурака".

### base_classes
Для всех классов созданы абстрактные классы, содержащие описание основной функциональности классов.

### vacancy
Вакансии обрабатываются в программе в виде объектов. У них выделены 5 основных атрибутов:
- название
- зарплата от
- зарплата до
- описание вакансии
- уникальная ссылка на вакансию, дабы пользователь имел возможность перейти по ней и посмотреть подробности

В классе реализованы все основные методы, необходимые для работы кода.

### hh_handler
Для получения данных с сайта www.hh.ru так же написан класс, который использует API ресурса. 
Код "выжимает" всё возможное из бесплатного варианта работы с ресурсом - получает до 2000 вакансий по одному запросу. 

### file_handler
Для работы с файлами так же создан класс, обладающий необходимой функциональностью.
Если при создании объектов класса не передать имя файла, то используется имя по умолчанию "vacancy.json"
Все файлы с информацией о вакансиях хранятся в корне проекта в папке data.

### utils
Все вспомогательные и сервисные функции, которые не имеют прямого отношения к "жизни" объектов в пределах своих 
классов, вынесены в модуль utils

Все функции проекта оттестированы в различных условиях: в штатных и нештатных, когда в параметрах всякая неожидаемая ерунда,
либо когда генераторы ничего не возвращают, за отсутствием подходящей под условия запроса информации. Дабы программа не падала с ошибками.

Покрытие проекта тестами соответствует ТЗ - более 70%
В репозиторий добавлен обновлённый файл с отчётом в html

Проект проверен линтерами

## Установка:

1. Клонируйте репозиторий:
```
git clonegit@github.com:Vadimko4/K4_Job_search.git
```
или
```
git clone https://github.com/Vadimko4/K4_Job_search.git
```

2. Установите зависимости:
```
poetry install
```
3. Ознакомьтесь с инструкцией в файле .env.example и донастройте окружение (введите свои API_KEY)

## Использование:

Запустите на выполнение файл main.py
